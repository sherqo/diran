# Shared TypeScript Types

This directory contains TypeScript types that are shared across different parts of the application. These types help maintain type safety and **consistency** throughout the codebase.
They include _definitions_ for various entities, _data structures_, _enums_, and _utility types_ used in the application.

it's not that big but good to **ensure** that backend and frontend use the same types and for me to remember stuff :)

## Organization

- Each file typically corresponds to a specific domain or feature of the application (e.g., User, Project, Block).
- Types are defined using TypeScript's type and interface syntax.
- Types are exported for use in other parts of the application.
- it can also contain enums and constants that are shared across the application.
